이미지·네이버 복붙·외부 URL도 「저장」 시 자동으로 우리 서버(R2)에 복사됩니다. URL 붙여넣기·텍스트 URL은 썸네일 카드가 됩니다. 「링크 가운데」로 카드 정렬을 바꿀 수 있습니다.

광고 픽셀 · 전환 태그

비워 두면 아무 것도 삽입되지 않습니다. 값이 있는 매체만 해당 글 HTML에 자동으로 들어갑니다. 각 매체 계정에서 복사한 ID만 넣으면 됩니다. (스크립트 통째로 붙여넣기는 맨 아래 「기타」)

Meta (페이스북·인스타) 입력됨

Meta 이벤트 관리자 → 데이터 소스 → 픽셀 ID (숫자).
입력 시 PageView 이벤트가 자동 전송됩니다.

TikTok 입력됨

TikTok Ads → 자산 → 이벤트 → 웹 픽셀 ID.
입력 시 page 뷰가 자동 전송됩니다.

Google (GA4 · Ads · GTM) 입력됨

쓰는 것만 넣으세요. 셋 다 넣어도 되고, 하나만 넣어도 됩니다.
· GA4: 측정 ID (G-XXXXXXXX)
· Google Ads: 전환 ID (AW-XXXXXXXX) + 전환 라벨
· GTM: 컨테이너 ID (GTM-XXXX) — GTM만 쓸 경우 GA4/Ads는 비워도 됩니다

네이버 (분석 · 검색광고) 입력됨

· 네이버 분석(WCS): 공통 스크립트의 wcs_add["wa"] 값
· 검색광고 전환: 전환 추적에 쓰는 전환 값/ID (있으면 전환 이벤트도 전송)
스크립트 전문이 아니라 ID 값만 넣어 주세요.

카카오 픽셀 입력됨

카카오 모먼트 → 픽셀 관리 → 픽셀 ID.
입력 시 pageView 가 자동 전송됩니다.

기타 · 커스텀 스크립트 입력됨

위 매체에 없는 태그(예: 크리테오, 애드피라 등)는 광고 콘솔에서 받은 <script>…</script> 를 그대로 붙여 넣으세요. 비우면 삽입되지 않습니다.

광고 블로그는 메인(index)에 노출되지 않습니다. 목록의 URL을 누르면 해당 광고 글로 이동합니다.
